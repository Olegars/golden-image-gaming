# Игровой профиль золотого образа

Один прогон Windows 11 Pro на эталонном ПК клуба, пока Super Client пишет диск image. Шелл эти настройки не применяет.

Запуск на эталоне от администратора, не на машине разработчика:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\Qt\golden-image-gaming\golden-image-gaming.ps1 -Apply
```

Без `-Apply` скрипт ничего не меняет. После прогона — перезагрузка, проверка и сохранение образа. Порядок и список того, что скрипт сознательно не трогает, — в главе «Игровой профиль золотого образа» документации клуба.
